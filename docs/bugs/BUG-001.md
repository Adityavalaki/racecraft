# BUG-001: Tyres and Strategy screens fitted tyre wear on later races
Symptom: For a past race, the Tyres screen, the strategy plans and the pit windows used tyre wear
fitted on every other race of the season, later ones included (2025 round 3 used rounds 4-24).
The README and `pit_view.py` promise "races before it".
Repro steps: `insight.for_session("2024_01_R")` on a lake with 2024 rounds 1-3: `fitted_on` listed
rounds 2 and 3. The old test `test_the_race_being_viewed_is_left_out_of_its_own_fit` asserted it.
Root cause: `SeasonFits.combined(exclude=key)` left out only the race itself (leave-one-out),
while the simulator's inputs (`race_inputs`) cut off at the race's start.
Fix: `combined(before_round=...)` keeps only lower rounds; a season's first race takes the last
five races of the season before, as `race_inputs` does. See DECISIONS D-001.
Verification: `test_a_race_is_fitted_only_on_the_races_before_it`,
`test_the_seasons_first_race_borrows_the_end_of_the_last`; insight, live, sync and API tests:
96 passed.
