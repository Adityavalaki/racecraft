# BUG-006: The replay's columns stack into one, at any window size

**Symptom:** The replay shows the pedal map, the followed-drivers box and the timing tower one
above another, each the full width; race control and team radio fall below the window.
Seen by Aditya, 2026-10-27, on a 1920 px screen at 125% (1536 CSS px).

**Repro:** Open the app on any session at any width (reproduced in headless Edge at 1536x864
with a fresh profile, so neither a saved layout nor the window size is involved).

**Root cause:** PR #4's merge (`82a07d8`, "Merge branch 'main' into race-control-and-stewards")
left three lines of an older `.grid` rule after the new one in `web/src/styles.css`:
`padding: 6px; min-height: 0; }`. A browser reads everything from there to the next `{` as one
selector, so `padding: 6px; min-height: 0; } .workspace` is an invalid selector, and the whole
`.workspace { display: flex; ... }` rule is dropped without an error. Without it the workspace's
three columns are plain blocks, one under another. The same merge broke `App.tsx` (fixed in
`41a03be`); this half was missed then. `177e8e5` and the branch's own `91b230c` are clean.

**Fix:** Delete the three stray lines.

**Verification:** `tests/test_web_styles.py` checks every `}` closes a `{` and that `.workspace`
is a flex row; it passes on the fix and catches the merged file. Web tests 243 passed, `vite
build` clean, and the built CSS no longer carries the stray text. (A vitest version was tried
first: vitest hands CSS to tests as empty text, so it would have passed while checking nothing.)
